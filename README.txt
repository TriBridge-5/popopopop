JAN-SAMADHAN SETU — GitHub Pages SINGLE-FILE MVP

Upload index.html to your GitHub repository. This version does NOT need:
- app.py
- admin.html
- login.html
- requirements.txt
- Flask
- Python
- database

GitHub Pages setup:
1. Replace/delete the old project files if you want a clean repository.
2. Upload index.html to the repository root.
3. Settings -> Pages -> Deploy from branch -> main -> / (root) -> Save.
4. Open the GitHub Pages URL.

The demo stores submitted challenges in browser localStorage, so it is suitable for an SIH demo but is not a shared production backend.
